출금 신청 방법

  1. 로그인 → 마이페이지
  2. 출금 메뉴 클릭
  3. 출금 계좌 입력 (본인 명의 필수)
  4. 출금 금액 입력
  5. 신청 완료 후 처리 대기

출금 지연 시 대처법

24시간 초과 → 고객센터 문의
48시간 초과 → 증거 캡처 시작
72시간 초과 → 먹튀 신고 접수
