5분 안전놀이터 셀프 체크

  1. 구글에서 "사이트명 + 먹튀" 검색 → 3개월 신고 없어야
  2. RGRE 검증 목록에서 검색 → 등록 여부 확인
  3. 도메인 WHOIS 조회 → 6개월 이상
  4. CS 채팅 테스트 → 5분 내 응답
  5. 1만원 출금 테스트 → 30분 내 처리

이 중 하나라도 실패하면?
